# Data-Driven Vinted Analytics

This project applies advanced statistical and econometric methodologies to a C2C market context: Vinted. This is a highly volatile ecosystem. The analysis is based on a dataset of ~2,000 shoes for sale, extracted via web scraping.

# Struttura del Progetto & Framework di Consulenza

The analysis of the Vinted dataset was structured to simulate a management consulting engagement for the platform, articulated into four analytical pillars:

1. **Pricing Recommendation Algorithm:** Development of a predictive model to estimate the sale price of similar products.

2. **Search Engine Optimization:** Analysis of the determinants of listing attractiveness, measured by the number of "favorites," to support the search engine development team.

3. **Quality Assessment and Perception:** Modeling of characteristics defining a "high-quality" product in the eyes of the community. Uses an Ordinal Probit regression to map the response variable.

4. **Network Analysis and Recommendation Systems:** Study of interdependencies between brands and user inventory habits. Conducted via Market Basket Analysis and Network Analysis. The goal is to generate a cross-selling recommendation algorithm for clusters of similar brands.
